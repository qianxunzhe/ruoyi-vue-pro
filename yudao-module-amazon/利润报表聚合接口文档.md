# 利润报表聚合接口文档

## 概述

利润报表聚合接口提供多维度的数据统计分析功能，支持按ASIN、SPU、SKU、店铺、日期等维度对销售数据进行聚合统计。

## 接口列表

### 1. 统一聚合查询接口

根据groupBy参数动态选择聚合维度。

**接口地址：** `/amazon/profit-report/aggregate`  
**请求方式：** GET  
**权限要求：** `amazon:profit-report:query`

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| startDate | string | 否 | 开始日期 | 2024-01-01 |
| endDate | string | 否 | 结束日期 | 2024-01-31 |
| groupBy | string | 否 | 聚合维度：ASIN/SPU/SKU/SID/SHOP/DATE，默认SKU | ASIN |
| asins | array | 否 | ASIN列表，用于筛选 | ["B001234567"] |
| spus | array | 否 | SPU列表，用于筛选 | ["SPU001"] |
| skus | array | 否 | SKU列表，用于筛选 | ["SKU001"] |
| sids | array | 否 | 店铺ID列表，用于筛选 | [101, 102] |
| sortField | string | 否 | 排序字段 | totalSales |
| sortOrder | string | 否 | 排序方式：ASC/DESC，默认DESC | DESC |
| pageNo | integer | 是 | 页码，从1开始 | 1 |
| pageSize | integer | 是 | 每页条数 | 20 |

#### 响应示例

根据groupBy参数不同，返回对应的聚合结果。

## 使用示例

### 1. 查询某个时间段内ASIN维度的销售数据

```bash
GET /amazon/profit-report/aggregate/asin?startDate=2024-01-01&endDate=2024-01-31&pageNo=1&pageSize=20
```

### 2. 查询特定店铺的SPU聚合数据

```bash
GET /amazon/profit-report/aggregate/spu?sids=[101,102]&startDate=2024-01-01&endDate=2024-01-31&pageNo=1&pageSize=20
```

### 3. 查询日期趋势（按天统计）

```bash
GET /amazon/profit-report/aggregate/date?startDate=2024-01-01&endDate=2024-01-31&pageNo=1&pageSize=31
```

### 4. 使用统一接口查询（推荐）

```bash
# ASIN维度
GET /amazon/profit-report/aggregate?groupBy=ASIN&startDate=2024-01-01&endDate=2024-01-31&pageNo=1&pageSize=20

# SPU维度
GET /amazon/profit-report/aggregate?groupBy=SPU&startDate=2024-01-01&endDate=2024-01-31&pageNo=1&pageSize=20

# 日期维度
GET /amazon/profit-report/aggregate?groupBy=DATE&startDate=2024-01-01&endDate=2024-01-31&pageNo=1&pageSize=31
```

## 注意事项

1. **日期格式**：日期参数使用 `yyyy-MM-dd` 格式，如：2024-01-01
2. **分页参数**：pageNo 从1开始，pageSize 建议不超过100
3. **排序**：默认按销售额降序排序，日期维度按日期升序排序
4. **权限**：所有接口都需要 `amazon:profit-report:query` 权限
5. **性能优化**：
   - 建议限制查询日期范围在3个月以内
   - 大数据量查询时适当减小 pageSize
   - 可通过筛选条件（asins、spus、skus、sids）减少数据量

## 字段说明

### 财务指标计算规则

1. **退货退款** = 销售退款额 + 费用退款额
2. **其他业务收入** = 买家运费 + 促销折扣 + FBA库存赔偿 + COD + 其他收入
3. **其他费用** = 其他订单费用 + 入库配置费 + FBA国际物流货运费 + 调整费用 + 平台其他费
4. **站外费** = 从otherFeeStr JSON字段中提取的站外费用总和
5. **毛利率(%)** = (毛利润 / 销售收入) × 100
6. **ACOS(%)** = (广告花费 / 广告销售额) × 100

### 主要财务指标

| 指标类别 | 字段名 | 说明 |
|---------|--------|------|
| **收入类** | | |
| | totalSalesAmount | 销售收入 |
| | otherRevenue | 其他业务收入 |
| **成本类** | | |
| | cgPriceTotal | 销售成本(采购成本) |
| | cgTransportCostsTotal | 头程运费 |
| | cgOtherCostsTotal | 其他业务成本 |
| **费用类** | | |
| | platformFee | 平台费 |
| | totalFbaDeliveryFee | 配送费 |
| | totalAdsCost | 广告费 |
| | promotionFee | 推广费 |
| | offsiteFee | 站外费 |
| | totalStorageFee | 仓储费 |
| | otherFee | 其他费用 |
| **利润类** | | |
| | grossProfit | 毛利润 |
| | grossRate | 毛利率(%) |

# 小类排名存储方式修改说明

## 修改目的
将小类排名的存储方式修改为与大类排名保持一致，便于统一管理和查询。

## 修改内容

### 1. 数据库字段变更
**原方式：**
- `small_cate_rank` - JSONB类型，存储所有小类的排名信息

**新方式：**
- `small_cate_rank` - INT类型，存储主要小类的排名（第一个小类）
- `prev_small_cate_rank` - INT类型，存储上一次的小类排名
- `small_rank_category` - VARCHAR(500)类型，存储小类排名分类名称
- `small_cate_rank_detail` - JSONB类型，保留完整的小类排名列表（包含所有小类）

### 2. 实体类修改
**文件：** `ProductPerformanceDO.java`
- 将`smallCateRank`从`List<SmallCateRank>`改为`Integer`类型
- 新增`prevSmallCateRank`字段（Integer）
- 新增`smallRankCategory`字段（String）
- 新增`smallCateRankDetail`字段（List<SmallCateRank>），保存完整的小类排名信息

### 3. 数据同步逻辑修改
**文件：** `ProductPerformanceServiceImpl.java`
- 在`convertDtoToDo`方法中，提取第一个小类的排名信息到独立字段
- 保留完整的小类排名列表到`smallCateRankDetail`字段

### 4. Mapper XML修改
**文件：** 
- `ProductPerformanceMapper.xml`
- `ProductPerformanceMapper_pgsql.xml`

**修改内容：**
- INSERT语句添加新字段
- UPDATE语句添加新字段
- 字段映射调整

### 5. 数据库脚本
**文件：** `add_small_cate_rank_fields.sql`
- 创建新的数据库字段
- 处理旧字段的重命名
- 添加必要的索引
- 提供数据迁移脚本（可选）

## 使用说明

### 1. 执行数据库脚本
```bash
# PostgreSQL
psql -d your_database -f add_small_cate_rank_fields.sql

# MySQL
mysql -u username -p your_database < add_small_cate_rank_fields.sql
```

### 2. 数据迁移（如果有历史数据）
如果需要迁移历史数据，可以执行SQL脚本中的数据迁移部分。

### 3. 验证
- 重新执行产品表现同步任务
- 检查新字段是否正确填充
- 验证查询功能是否正常

## 优势
1. **统一性**：与大类排名保持一致的存储方式
2. **查询效率**：可以直接通过字段查询，无需解析JSON
3. **灵活性**：保留了完整的小类排名详情，不丢失信息
4. **兼容性**：新旧数据格式可以共存，便于平滑迁移

## 注意事项
1. 确保数据库已执行相关SQL脚本
2. 同步任务会自动使用新的存储方式
3. 旧数据需要手动迁移或重新同步

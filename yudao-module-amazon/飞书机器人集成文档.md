# 飞书机器人集成文档

## 一、概述

本文档介绍如何在Amazon模块中集成和使用飞书机器人通知功能。飞书机器人可以将系统的重要事件、任务状态、异常告警等信息实时推送到飞书群组。

## 二、核心组件说明

### 2.1 配置类
- **位置**: `cn.iocoder.yudao.module.amazon.config.FeishuConfig`
- **功能**: 管理飞书机器人的配置信息，包括webhook地址、超时设置、重试机制等

### 2.2 服务接口
- **位置**: `cn.iocoder.yudao.module.amazon.service.feishu.FeishuNotificationService`
- **功能**: 定义了发送各种类型飞书消息的接口方法

### 2.3 服务实现
- **位置**: `cn.iocoder.yudao.module.amazon.service.feishu.FeishuNotificationServiceImpl`
- **功能**: 实现飞书消息发送逻辑，包括重试机制、异常处理等

### 2.4 数据模型
- **FeishuMessageDTO**: 飞书消息数据传输对象
- **FeishuResponseDTO**: 飞书响应数据对象
- **FeishuMessageTypeEnum**: 消息类型枚举（文本、富文本、卡片等）
- **FeishuSceneEnum**: 通知场景枚举（任务完成、数据同步、异常告警等）

## 三、配置说明

### 3.1 application.yml 配置

```yaml
amazon:
  feishu:
    enabled: true  # 是否启用飞书通知
    default-webhook: https://open.feishu.cn/open-apis/bot/v2/hook/your-default-webhook  # 默认webhook
    timeout: 5000  # 超时时间（毫秒）
    retry-times: 3  # 重试次数
    retry-interval: 1000  # 重试间隔（毫秒）
    webhooks:  # 不同场景的webhook配置
      task-complete: https://open.feishu.cn/open-apis/bot/v2/hook/task-webhook
      error-notification: https://open.feishu.cn/open-apis/bot/v2/hook/error-webhook
      data-sync-success: https://open.feishu.cn/open-apis/bot/v2/hook/sync-webhook
      keyword-ranking-change: https://open.feishu.cn/open-apis/bot/v2/hook/ranking-webhook
      price-change: https://open.feishu.cn/open-apis/bot/v2/hook/price-webhook
      review-alert: https://open.feishu.cn/open-apis/bot/v2/hook/review-webhook
```

### 3.2 获取飞书机器人Webhook

1. 打开飞书群组设置
2. 选择"群机器人" -> "添加机器人"
3. 选择"自定义机器人"
4. 设置机器人名称和描述
5. 复制生成的Webhook地址

## 四、使用方式

### 4.1 注入服务

```java
@Autowired
private FeishuNotificationService feishuNotificationService;
```

### 4.2 发送文本消息

```java
// 发送简单文本消息
feishuNotificationService.sendTextMessage("这是一条测试消息");

// 发送到指定场景
feishuNotificationService.sendTextMessage("任务完成", FeishuSceneEnum.TASK_COMPLETE);

// 发送到指定webhook
feishuNotificationService.sendTextMessage("自定义消息", "https://your-webhook-url");
```

### 4.3 发送富文本消息

```java
// 创建富文本内容
Object[][] content = new Object[][]{
    {new Object[]{"text", "第一行内容"}},
    {new Object[]{"text", "第二行内容", "style", new String[]{"bold"}}}
};

feishuNotificationService.sendPostMessage(
    "富文本标题", 
    content, 
    FeishuSceneEnum.DEFAULT
);
```

### 4.4 使用预定义通知方法

```java
// 任务完成通知
feishuNotificationService.notifyTaskComplete(
    "关键词排名监控任务",
    "执行成功",
    "处理了100个关键词"
);

// 任务失败通知
feishuNotificationService.notifyTaskFailed(
    "数据同步任务",
    "连接超时",
    "详细错误堆栈信息..."
);

// 数据同步成功通知
feishuNotificationService.notifyDataSyncSuccess(
    "产品数据",
    1000,  // 同步数量
    60     // 耗时（秒）
);

// 数据同步失败通知
feishuNotificationService.notifyDataSyncFailed(
    "订单数据",
    "API调用限制超额"
);

// 关键词排名变化通知
feishuNotificationService.notifyKeywordRankingChange(
    "wireless charger",  // 关键词
    "B08ABC123",         // ASIN
    15,                  // 旧排名
    8                    // 新排名
);

// 价格变动通知
feishuNotificationService.notifyPriceChange(
    "B08ABC123",         // ASIN
    "无线充电器",         // 商品标题
    29.99,               // 旧价格
    24.99                // 新价格
);

// 评论预警通知
feishuNotificationService.notifyReviewAlert(
    "B08ABC123",         // ASIN
    "无线充电器",         // 商品标题
    2,                   // 评分
    "产品质量很差..."    // 评论内容
);
```

## 五、集成示例

### 5.1 在定时任务中集成

```java
@Component
public class DataSyncJob {
    
    @Autowired
    private FeishuNotificationService feishuNotificationService;
    
    @Scheduled(cron = "0 0 * * * ?")
    public void syncData() {
        try {
            // 执行数据同步
            int count = performDataSync();
            
            // 发送成功通知
            feishuNotificationService.notifyDataSyncSuccess(
                "产品数据", 
                count, 
                System.currentTimeMillis() / 1000
            );
        } catch (Exception e) {
            // 发送失败通知
            feishuNotificationService.notifyDataSyncFailed(
                "产品数据",
                e.getMessage()
            );
            throw e;
        }
    }
}
```

### 5.2 在业务服务中集成

```java
@Service
public class KeywordTaskServiceImpl implements KeywordTaskService {
    
    @Autowired
    private FeishuNotificationService feishuNotificationService;
    
    public Long createTask(TaskCreateVO vo) {
        try {
            // 创建任务
            Long taskId = doCreateTask(vo);
            
            // 发送通知
            feishuNotificationService.notifyTaskComplete(
                "任务创建成功",
                "任务ID: " + taskId,
                "任务名称: " + vo.getTaskName()
            );
            
            return taskId;
        } catch (Exception e) {
            // 发送错误通知
            feishuNotificationService.notifyTaskFailed(
                "任务创建失败",
                e.getMessage(),
                ExceptionUtils.getStackTrace(e)
            );
            throw e;
        }
    }
}
```

### 5.3 在异常处理中集成

```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    
    @Autowired
    private FeishuNotificationService feishuNotificationService;
    
    @ExceptionHandler(BusinessException.class)
    public Result handleBusinessException(BusinessException e) {
        // 发送异常通知到飞书
        feishuNotificationService.sendTextMessage(
            String.format("❌ 业务异常\\n模块：%s\\n错误：%s\\n时间：%s",
                "Amazon模块",
                e.getMessage(),
                LocalDateTime.now()
            ),
            FeishuSceneEnum.ERROR_NOTIFICATION
        );
        
        return Result.fail(e.getMessage());
    }
}
```

## 六、通知场景枚举说明

| 场景代码 | 说明 | 适用场景 |
|---------|------|---------|
| DEFAULT | 默认通知 | 一般性通知信息 |
| TASK_START | 任务开始 | 定时任务或批处理任务开始执行 |
| TASK_COMPLETE | 任务完成 | 任务执行成功完成 |
| TASK_FAILED | 任务失败 | 任务执行失败 |
| ERROR_NOTIFICATION | 错误通知 | 系统错误或异常 |
| DATA_SYNC_SUCCESS | 数据同步成功 | 数据同步任务成功 |
| DATA_SYNC_FAILED | 数据同步失败 | 数据同步任务失败 |
| KEYWORD_RANKING_CHANGE | 关键词排名变化 | 监控到关键词排名发生变化 |
| PRICE_CHANGE | 价格变动通知 | 商品价格发生变化 |
| REVIEW_ALERT | 评论预警 | 收到低分评论或负面评论 |
| PROFIT_REPORT | 利润报表通知 | 利润报表生成或异常 |

## 七、最佳实践

### 7.1 错误处理
- 始终在try-catch块中包装飞书通知调用，避免通知失败影响主流程
- 记录日志，便于排查通知发送问题

### 7.2 消息格式
- 使用emoji表情增强可读性（✅成功 ❌失败 ⚠️警告 📊数据）
- 保持消息简洁，突出关键信息
- 长文本使用StrUtil.maxLength限制长度

### 7.3 通知频率控制
- 避免频繁发送相同类型的通知
- 可以考虑批量汇总后发送
- 设置合理的通知级别，避免信息过载

### 7.4 配置管理
- 不同环境使用不同的webhook
- 生产环境的重要通知使用独立的webhook
- 定期检查webhook的有效性

## 九、常见问题

### Q1: 消息发送失败怎么办？
A: 检查以下几点：
- webhook地址是否正确
- 网络是否可达飞书服务器
- 配置文件中enabled是否为true
- 查看日志中的具体错误信息

### Q2: 如何调试消息格式？
A: 可以先使用curl或Postman直接调用webhook接口测试消息格式

### Q3: 如何控制不同环境的通知？
A: 通过配置文件的enabled开关和不同的webhook地址来控制

### Q4: 消息发送有频率限制吗？
A: 飞书机器人有频率限制，建议控制在每分钟20条以内

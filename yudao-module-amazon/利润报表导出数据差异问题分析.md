# 利润报表导出数据差异问题分析

## 问题描述
用户反馈：导出聚合利润报表时，查询时毛利润和毛利率都正确，但导出的数据发生了变化。

## 问题分析

### 代码流程分析
1. **查询接口** (`/aggregate/sku`)：
   - Controller调用 `profitReportService.aggregateBySku(queryVO)`
   - Service从数据库获取原始数据，通过`buildSkuAggVO`方法聚合

2. **导出接口** (`/export-aggregate-excel`)：
   - Controller调用相同的Service方法
   - 使用ExcelUtils导出数据

3. **计算逻辑**：
   - 毛利润：从数据库直接聚合 `sumBigDecimal(skuData, ProfitReportDO::getGrossProfit)`
   - 毛利率：重新计算 `毛利润 ÷ 销售额 × 100`

### 可能原因

1. **查询参数不一致**（最可能）
   - 前端查询和导出时传递的参数不同
   - 日期范围、店铺筛选、SKU/ASIN筛选等条件不同

2. **数据更新时机**
   - 在查询和导出之间，数据库中的数据被重新同步更新

3. **毛利率计算精度问题**
   - 数据库存储的值来自领星API
   - 聚合时重新计算可能导致精度差异

## 已实施的修复

### 1. 添加调试日志
在Controller中添加了日志记录，便于排查参数差异：

```java
// 查询接口日志
log.info("查询SKU聚合数据 - 参数: startDate={}, endDate={}, sids={}, asins={}, skus={}", 
    queryVO.getStartDate(), queryVO.getEndDate(), 
    queryVO.getSids(), queryVO.getAsins(), queryVO.getSkus());

// 导出接口日志
log.info("导出聚合数据 - 参数: groupBy={}, startDate={}, endDate={}, sids={}, asins={}, skus={}", 
    queryVO.getGroupBy(), queryVO.getStartDate(), queryVO.getEndDate(), 
    queryVO.getSids(), queryVO.getAsins(), queryVO.getSkus());
```

## 排查步骤

1. **检查日志**
   ```bash
   # 查看查询和导出的参数日志
   tail -f logs/application.log | grep "聚合数据"
   ```

2. **对比参数**
   - 确认查询和导出使用了相同的日期范围
   - 确认店铺、SKU、ASIN等筛选条件一致

3. **验证数据一致性**
   - 在同一时间点执行查询和导出
   - 对比结果中的具体数值

## 临时解决方案

如果确认是参数不一致导致：
1. 前端开发需要确保导出时传递与查询相同的参数
2. 可以考虑在前端缓存查询参数，导出时使用缓存的参数

## 后续优化建议

1. **添加数据版本控制**
   - 在数据同步时记录版本号
   - 查询和导出时返回数据版本，便于对比

2. **优化毛利率计算**
   - 统一使用数据库存储的值或重新计算的值
   - 避免混用导致的精度差异

3. **添加数据一致性校验**
   - 导出前校验关键指标
   - 发现差异时给出提示

# 产品表现字段映射修复说明

## 问题描述
PostgreSQL数据库中的字段命名规则与MyBatis默认的驼峰转下划线规则不一致，导致查询时出现字段不存在的错误。

## 错误示例
```sql
ERROR: column "inventory_age0_to90" does not exist
建议：Perhaps you meant to reference the column "amazon_product_performance.inventory_age_0_90".

ERROR: column "p_1_keywords" does not exist
建议：Perhaps you meant to reference the column "amazon_product_performance.p1_keywords".
```

## 修复内容
在 `ProductPerformanceDO.java` 中为以下字段添加了 `@TableField` 注解，指定数据库中的实际字段名：

| Java字段名 | 数据库字段名 | 说明 |
|-----------|-------------|------|
| p1Keywords | p1_keywords | P1关键词数量 |
| p2Keywords | p2_keywords | P2关键词数量 |
| p3Keywords | p3_keywords | P3关键词数量 |
| inventoryAge0To90 | inventory_age_0_90 | 0-90天库龄 |
| inventoryAge91To180 | inventory_age_91_180 | 91-180天库龄 |
| inventoryAge180Plus | inventory_age_180_plus | 180+天库龄 |
| storageFee30Days | storage_fee_30_days | 30天仓储费 |
| storageFee180To365Quantity | storage_fee_180_365_quantity | 180-365天收费数量 |
| storageFee180To365Amount | storage_fee_180_365_amount | 180-365天收费金额 |

## 修复代码示例
```java
/**
 * 0-90天库龄
 */
@TableField("inventory_age_0_90")
private Integer inventoryAge0To90;
```

## 数据库字段命名规则
PostgreSQL中的实际命名规则：
- 普通单词之间用下划线分隔：`create_time`
- P系列关键词：`p1_keywords`（数字前不加下划线）
- 库龄字段：`inventory_age_0_90`（数字前后都有下划线，但是对于范围表示不用"to"）
- 仓储费字段：`storage_fee_180_365_quantity`（数字范围直接用下划线连接，不用"to"）

## 影响范围
- 所有包含数字的字段都需要检查是否符合数据库的命名规则
- 前端调用API时使用Java字段名（驼峰命名）
- 数据库查询时会自动映射到正确的数据库字段名（下划线命名）

## 验证方法
1. 重启应用
2. 调用产品表现分页查询接口
3. 确认不再出现字段不存在的错误

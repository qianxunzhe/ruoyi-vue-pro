# 毛利率计算公式修正说明

## 修改时间
2025-08-26

## 问题描述
原毛利率计算公式使用销售额作为分母，导致毛利率计算不准确。

## 修正内容

### 原公式
```
毛利率 = 毛利润 ÷ 销售额 × 100
```

### 新公式
```
净销售额 = 销售额 + 买家运费 + 促销折扣 + FBA库存赔偿 + COD + 其他收入 + 收入退款项 + 费用退款项
毛利率 = 毛利润 ÷ 净销售额 × 100
```

### 字段映射
- **销售额**: `totalSalesAmount`
- **买家运费**: `shippingCredits`
- **促销折扣**: `promotionalRebates`
- **FBA库存赔偿**: `fbaInventoryCredit`
- **COD**: `cashOnDelivery`
- **其他收入**: `otherInAmount`
- **收入退款项**: `totalSalesRefunds`
- **费用退款项**: `totalFeeRefunds`

在聚合VO中已计算：
- **其他业务收入** (`otherRevenue`) = 买家运费 + 促销折扣 + FBA库存赔偿 + COD + 其他收入
- **退货退款** (`totalRefunds`) = 收入退款项 + 费用退款项

因此，简化公式为：
```
净销售额 = totalSalesAmount + otherRevenue + totalRefunds
毛利率 = grossProfit ÷ 净销售额 × 100
```

## 修改的文件和方法

### ProfitReportServiceImpl.java

1. **calculateRates(ProfitReportSkuAggVO vo)** - SKU聚合毛利率计算
2. **buildSpuAggVO** - SPU聚合毛利率计算
3. **buildShopAggVO** - 店铺聚合毛利率计算  
4. **buildAsinAggVO** - ASIN聚合毛利率计算
5. **buildDateAggVO** - 日期聚合毛利率计算
6. **convertToManagementReport** - 管理报表毛利率计算

## 影响范围

所有利润报表聚合查询接口的毛利率计算都已更新：
- `/aggregate/sku` - SKU维度聚合
- `/aggregate/spu` - SPU维度聚合
- `/aggregate/shop` - 店铺维度聚合
- `/aggregate/asin` - ASIN维度聚合
- `/aggregate/date` - 日期维度聚合
- `/aggregate` - 统一聚合查询
- `/export-aggregate-excel` - 导出聚合数据

## 注意事项

1. **退货退款通常为负值**，会减少净销售额
2. 当净销售额为0或负数时，不计算毛利率
3. 毛利率保留4位小数，显示时乘以100转换为百分比

## 验证方法

1. 查询任一聚合接口，检查毛利率是否按新公式计算
2. 导出数据，确认导出的毛利率与查询结果一致
3. 对比原始数据：毛利润 ÷ (销售额 + 其他业务收入 + 退货退款) = 毛利率

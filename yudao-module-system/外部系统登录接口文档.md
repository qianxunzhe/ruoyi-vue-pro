# 外部系统登录接口文档

## 接口概述
本接口专为外部系统（如AMZMoss）提供登录认证服务，支持账号密码登录方式，无需验证码验证。

## 接口信息

### 基本信息
- **接口名称**：外部系统登录接口
- **接口路径**：`/admin-api/system/auth/login-amzmoss`
- **请求方式**：POST
- **Content-Type**：application/json
- **权限要求**：无需认证（@PermitAll）

### 接口地址
```
POST https://{domain}/admin-api/system/auth/login-amzmoss
```

## 请求参数

### 请求体（Body）
| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|---------|
| username | String | 是 | 登录账号<br>- 长度：4-16位<br>- 格式：仅支持字母和数字 | "admin" |
| password | String | 是 | 登录密码<br>- 长度：4-16位 | "admin123" |

### 请求示例
```json
{
    "username": "admin",
    "password": "admin123"
}
```

## 响应参数

### 响应体结构
| 参数名 | 类型 | 说明 | 示例值 |
|--------|------|------|---------|
| code | Integer | 响应码<br>- 0：成功<br>- 其他：失败 | 0 |
| msg | String | 响应消息 | "成功" |
| data | Object | 响应数据对象 | - |
| data.userId | Long | 用户编号 | 1024 |
| data.accessToken | String | 访问令牌（用于后续API调用） | "2e3d7635-c537-4578-ae5e-5f3503c9d6ef" |
| data.refreshToken | String | 刷新令牌（用于刷新访问令牌） | "6c1f7e85-86f2-4b91-bce2-1e0f3c3a5b8c" |
| data.expiresTime | String | 令牌过期时间（ISO 8601格式） | "2024-01-20T10:30:00" |

### 成功响应示例
```json
{
    "code": 0,
    "msg": "成功",
    "data": {
        "userId": 1024,
        "accessToken": "2e3d7635-c537-4578-ae5e-5f3503c9d6ef",

        "expiresTime": "2024-01-20T10:30:00"

```

## 错误码说明

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 0 | 成功 | - |
| 400 | 参数验证失败 | 检查请求参数格式是否正确 |
| 1001000000 | 账号密码不正确 | 检查用户名和密码是否正确 |
| 1001000001 | 账号被禁用 | 联系管理员启用账号 |
| 500 | 服务器内部错误 | 稍后重试或联系技术支持 |

## Token使用说明

### 1. Token类型
- **Access Token（访问令牌）**：用于访问受保护的API资源
- **Refresh Token（刷新令牌）**：用于在Access Token过期时获取新的Access Token

### 2. Token使用方式
在后续API请求中，需要在请求头中携带Access Token：
```
Authorization: Bearer {accessToken}
```

示例：
```bash
curl -X GET https://{domain}/admin-api/system/user/profile \
  -H "Authorization: Bearer 2e3d7635-c537-4578-ae5e-5f3503c9d6ef"
```

### 3. Token过期处理
- Access Token默认有效期：2小时
- Refresh Token默认有效期：30天
- 当Access Token过期时，使用Refresh Token调用刷新接口获取新的Token对

## 接口特点

### 与普通登录接口的区别
1. **无需验证码**：跳过图形验证码校验，提高外部系统调用效率
2. **不支持社交登录绑定**：纯账号密码认证，不支持第三方社交账号绑定
3. **专用接口路径**：使用独立的接口路径，便于权限控制和流量监控

### 安全建议
1. **IP白名单**：建议在生产环境配置IP白名单，限制调用来源
2. **频率限制**：建议实施接口调用频率限制，防止暴力破解
3. **HTTPS传输**：必须使用HTTPS协议传输，确保密码安全
4. **密码复杂度**：建议使用强密码，定期更换
5. **监控告警**：建议监控异常登录行为，如频繁失败、异地登录等

## 调用示例

### Java示例
```java
import org.springframework.web.client.RestTemplate;
import org.springframework.http.*;

public class LoginExample {
    public static void main(String[] args) {
        RestTemplate restTemplate = new RestTemplate();
        
        // 构建请求体
        Map<String, String> request = new HashMap<>();
        request.put("username", "admin");
        request.put("password", "admin123");
        
        // 设置请求头
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);
        
        // 发送请求
        HttpEntity<Map<String, String>> entity = new HttpEntity<>(request, headers);
        ResponseEntity<Map> response = restTemplate.postForEntity(
            "https://api.example.com/admin-api/system/auth/login-amzmoss",
            entity,
            Map.class
        );
        
        // 处理响应
        if (response.getBody().get("code").equals(0)) {
            Map data = (Map) response.getBody().get("data");
            String accessToken = (String) data.get("accessToken");
            System.out.println("登录成功，Token: " + accessToken);
        }
    }
}
```

### Python示例
```python
import requests
import json

def login():
    url = "https://api.example.com/admin-api/system/auth/login-amzmoss"
    
    # 请求参数
    payload = {
        "username": "admin",
        "password": "admin123"
    }
    
    # 发送请求
    response = requests.post(url, json=payload)
    result = response.json()
    
    # 处理响应
    if result["code"] == 0:
        access_token = result["data"]["accessToken"]
        print(f"登录成功，Token: {access_token}")
        return access_token
    else:
        print(f"登录失败: {result['msg']}")
        return None

if __name__ == "__main__":
    token = login()
```

## 注意事项
1. 本接口专为外部系统集成设计，请勿用于前端直接调用
2. 建议在服务端调用此接口，避免暴露敏感信息
3. 获取的Token需要妥善保管，避免泄露
4. 建议实现Token缓存机制，避免频繁登录
5. 生产环境建议启用接口访问日志，便于安全审计
